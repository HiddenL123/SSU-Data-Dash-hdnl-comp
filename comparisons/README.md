# Feature research helpers

Run from the checkout root with `python -m comparisons.text_benchmark --help`,
`python -m comparisons.comparable_benchmark --help`, or
`python -m comparisons.avm_realworld_shotgun --help`.
The original root scripts remain compatible CLI/import aliases.
These helpers evaluate the implementations in `features/` using existing models;
experiment definitions, chronological folds and relative output paths are unchanged.
